Motion is visibly present through page bodies and browsing actions. Treat media and copy as one unit. There is no word-by-word headline animation, continuous photo zoom, decorative loop, or scroll hijacking. ## Runtime contract

Reuse installed GSAP with scoped React cleanup, media contexts, and cancellation. Shared SiteMotion stays outside the initial module graph and preloads in parallel with language and the initial PageContent commit. The application remains measurable behind an inert, aria-hidden startup layer; SiteMotion mounts disabled and activates only after the intro exits, so the first Home entrance remains visible. First activation and route effects scan fresh content; subsequent reduced-motion media re-entry settles visible content. One observer handles prepared content, unobserves completed/removed targets, and disconnects on navigation. A persistent completed-node weak set and an effect-local active set distinguish finished scenes from in-flight work. Interrupted Strict Mode cleanup does not mark unfinished scenes complete. Preparation runs in the GSAP context so asynchronous sets also revert when reduced motion changes. Body effects use individual CSS translate so they do not overwrite CSS hover transforms.

GSAP owns authored page entrances and action-dependent transitions, using gentle `sine.out` easing. Defaults remain visible and no CSS startup animation competes with GSAP. Existing hover feedback and Radix exit-presence CSS remain independent. Header, invitation, and document-intro SVG draws are finite. JourneyLoader's retained `introStartedAt` and `exitStartedAt` clocks exclusively own completion; its optional GSAP module has no callbacks and never resets logo/label/orbit visibility. Late decoration and exit seek elapsed time; all finite-intro child animations are bounded and the glow has one owner. Unmounting releases timelines, observers, and visibility listeners. Asset preparation writes generated JSON only when content changes, preventing build-triggered module reloads from restarting the app. Other new motion uses transform/opacity. No animated blur, permanent GPU hints, per-frame React state, or new dependency. Existing localized disclosure height measurement remains isolated.

Reduced motion leaves content and geometry visible, skips spatial GSAP/CSS effects, disables carousel autoplay, and retains selected, focus, validation, loading, success, and error states. The document intro uses static branding for its required minimum and exits immediately when ready; internal navigation, requests, responses, and actual value changes receive no artificial delay. Preserve Radix modal semantics, Escape, focus trapping/return, native disclosure semantics, and chat behavior.
